## 二、合规性说明

1. 本项目数据获取**严格采用课程白名单方式**——数据源官方提供的一次性下载文件（ZIP/CSV），**未使用任何爬虫技术**（不含 Scrapy、Selenium、requests 网页解析、模拟登录抓取等）。
2. 该数据集位于课程《期末大作业要求》附件 A 推荐数据源清单（Kaggle·Olist 巴西电商）。
3. 数据由 Olist 官方脱敏发布，客户标识已替换为匿名化 `customer_unique_id`，不含任何可直接识别个人身份的信息。
4. 本项目仅用于课程学习与非商业学术用途，遵循 CC BY-NC-SA 4.0 协议：已署名数据来源、未用于商业目的、衍生成果以相同方式共享。
